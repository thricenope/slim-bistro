# 轻卡小馆 SlimBistro

> 休闲治愈风减肥打卡：经营一家只做晚饭的Q版小馆。录四件菜况 → 今日招牌菜出锅 → 星级与常客满意度；≥2 分好评如潮、≥6 分满分招牌。不打怪、无输赢压力。

- 在线体验：<https://thricenope.github.io/slim-bistro/>（数据存在浏览器本地，换设备请用应用内导出/导入）
- 技术栈：Vite + React 18 + TypeScript + zustand(persist) + framer-motion，纯前端 localStorage
- 本地开发：`npm install && npm run dev` → http://localhost:5195

## 玩法

1. 晚饭后录四件菜况：几点吃 / 吃了多少 / 喝没喝饮料 / 动没动
2. 点「开饭！」——评分越高星级越高，常客小动物捧碗转圈
3. 连续好评推进「小店招牌」成长链，收 6 位Q版常客（周末神秘美食家）
4. 账本看经营统计；数据可导出/导入
